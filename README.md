設定したら、一番下の Create repository を押してね。

STEP 3. READMEを編集する
リポジトリができたら、

README.md をクリック

鉛筆マーク（Edit this file）をクリック

最初から入っている文章を削除

さっき作ったREADME全文を貼り付け

右上の Commit changes をクリック

Commit message は Initial portfolio README でOK

これで最初の公開ページができるよ。
